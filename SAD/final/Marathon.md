# Systems Analysis and Design (SAD) — 1‑Day Marathon Plan (Target 30+)

This plan is based on repetition across **2076, 2078–2081 + Model** (6 sets total). Frequency is interpreted as “topic appears in x out of 6 sets”.

## Assumptions

- You are starting from zero (no prior knowledge).
- You have only one day to prepare.
- Goal: **30+ marks** (pass-first, then safer buffer).

## What to optimize for (exam reality)

- **Group A (long):** attempt any **2 out of 3** (≈10 marks each)
- **Group B (short):** attempt any **8 out of 12** (≈5 marks each)

A practical “30+” approach:

- Lock **2 reliable long answers** (≈20 marks), and
- Be ready for **10+ short answers**, so you can choose the best 8.

## 4) One‑day schedule (hour‑by‑hour)

Use “Hour 0” as your start time. The rule for SAD is: **write answers and draw diagrams**, not just reading.

### Hour 0: Setup (30–45 min)

Create a 2-page “exam sheet” with these templates:

- DFD symbols + naming rules (process/data store/data flow)
- “Balancing” explanation (4–6 lines)
- SDLC phases + compare table: waterfall vs prototyping vs agile
- Requirements methods compare table: JAD vs interview vs observation vs prototyping
- Feasibility categories table (technical/economic/operational/schedule)
- Financial template:
  - Payback and discounted payback table format
  - NPV formula outline: $NPV=\sum \frac{(Benefits-Costs)}{(1+r)^t}$
- CASE tools: definition + components + phase-wise role
- Project management: phases + 5 skills + PERT vs network diagram keywords
- Maintenance: 4 types + examples
- OO: use case elements + class diagram box + common relationships

Deliverable: 2 pages you will revise at the end.

### Hours 1–2.5: Unit 3 (P1) — Requirements determination methods

Target outcome: you can answer any “requirements methods” short question in 5 minutes.

- Learn the 4–6 methods and write a compare table:
  - JAD, group interview, observation, prototyping (throwaway vs evolutionary), disruptive/radical methods
- Practice (write answers):
  - 2076-B8, 2078-B8, 2079-B7, 2080-B7, 2081-B9

### Hours 2.5–4.5: Unit 3 (P1) — DFD + balancing

Target outcome: you can draw context + level‑0 and explain balancing.

- Practice 2 complete DFDs:
  - Retail clothing store / online movie rental / mess management (use any 2 from refs)
- For each: draw context → level‑0, then do one decomposition (level‑1) for a major process.

Refs: 2076-A3, 2079-A2, 2080-A2, Model-A2

### Hours 4.5–5.5: Unit 3 (P2) — Structured logic

Target outcome: you can convert a policy into structured English + decision table.

- Learn:
  - conditions/actions, rules, and “reduced decision table”
- Practice:
  - Model-A3 (bank deposit policy)
  - 2081-A2 (reduced decision table scenario)

### Hours 5.5–7: Unit 1 (P1) — SDLC + approaches

Target outcome: second strong long answer option.

- Write:
  - SDLC phases (with 1–2 lines each)
  - Waterfall problems (at least 5)
  - Prototyping: advantages + disadvantages
  - Agile: 4–6 key points
- Practice:
  - 2076-A1 or 2080-A1

### Hours 7–8.25: Unit 2 (P1) — Feasibility + initiation/planning

Target outcome: 2–3 guaranteed short answers.

- Feasibility categories + “how to write economic feasibility”
- Project initiation & planning steps + baseline plan outputs

Refs:

- Feasibility: 2076-A2, 2080-B6, Model-B11
- Initiation/planning: 2076-B6, 2078-B7, 2079-B6

### Hours 8.25–9.5: Unit 2 (P1) — Financial numericals (NPV/payback)

Target outcome: you can complete one NPV/payback problem without panic.

- Prepare one clean template:
  - list yearly cash flows
  - compute PV factor and PV inflow
  - compute cumulative PV to find discounted payback
  - one-line interpretation

Practice:

- 2081-B11 (discounted payback)
- Model-B9 (payback)
- If time remains: 2078-A2 (NPV + ROI + breakeven)

### Hours 9.5–10.25: Unit 1 (P1) — Project management + PERT/network

Target outcome: 1–2 easy short answers.

- Phases/activities + key skills
- PERT vs network diagram: what they represent + key terms

Refs: 2078-B6, 2079-B4, 2080-B4/B12, 2081-B4/B12

### Hours 10.25–11: Unit 1 (P1) — CASE tools

Target outcome: a clean structured 5-mark answer.

- Definition + components + how CASE supports SDLC phases

Refs: 2078-B5, 2079-B11, 2081-B5

### Hours 11–12: Unit 5 + Unit 6 (P1/P2) — Maintenance + testing + OO diagrams

Target outcome: fill remaining short answers.

  - 4 types + major activities (Refs: 2076-B10, 2079-B10, 2080-B10)
