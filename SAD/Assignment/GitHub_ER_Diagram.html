GitHub Core System - ER Diagram

Standard Chen notation (entities, attributes, relationships)

Standard ER Diagram Components

Entity (Rectangle)

Represents a real-world object or concept that is stored in the system.

Attribute (Ellipse)

Represents a property of an entity (e.g., username, repo_name).

Relationship (Diamond)

Represents an association between entities (e.g., Owns, Has, Member).

Key Attribute

A key attribute is shown by underlining the attribute name.

Cardinality

1 indicates one, N indicates many, and M indicates many in M:N relationships.

Participation (Optional)

Total participation can be shown with a double line; optional participation can be shown with a single line.
