# WT Internal Exam Trend Analysis (Coverage: Unit 1 to Unit 5)

## Scope

- Papers analyzed: 2076, 2078, 2079, 2080, 2081, 2082, Model Question.
- Syllabus boundary used: Unit 1 to Unit 5.
- Unit 6 (PHP) questions are present in papers but excluded from priority ranking for this analysis.

## Most Frequently Asked Topics (Unit 1 to Unit 5)

### Very High Frequency

- XML core: XML structure, simple/complex elements, attributes, nested elements.
- XML schema languages: DTD and XSD creation, comparison, validation constraints.
- HTML form creation with JavaScript validation rules.
- jQuery: selectors, animate, chaining, callback effects.
- Web basics: web client, web server, static vs dynamic, Web 1.0 vs Web 2.0.

### High Frequency

- CSS positioning and layout: relative, absolute, float, fixed; internal/external CSS usage.
- CSS box model and selector usage (id/class).
- HTML events and JavaScript events: keypress, keydown, onload, prompt/alert.
- Core HTML scripting tasks: links, meta tag, table/list/audio/canvas based scripts.

### Medium Frequency

- JSON basics: data types, parsing, usage.
- AJAX and XMLHttpRequest basics.
- XML namespace and XSLT transformation.

## Frequency Snapshot (Across 7 Sets)

- XML + DTD/XSD family: very frequent (appears in almost every paper, often in Section A).
- HTML form + JavaScript validation: very frequent (about 5/7).
- jQuery selectors/animate/chaining: very frequent (about 6/7).
- Web basics (client/server, Web 1.0/2.0, static/dynamic): high (about 6/7).
- CSS positioning/selectors/box model/effects: high (about 6/7).
- JS arrays/events/DOM/popup basics: high (about 5/7).
- JSON and AJAX/XHR: medium (about 2-3/7).

## Most Probable Questions (Up to Unit 5)

- Create XML with nested elements and attributes; write equivalent DTD or XSD.
- Create XSD with restrictions (range, enumeration, length/type constraints).
- Compare DTD and XSD with key points.
- Build HTML form and implement JavaScript validation for required fields and pattern constraints.
- Explain and demonstrate jQuery selectors, animate, callback, and chaining.
- Explain web client vs web server; static vs dynamic pages; Web 1.0 vs Web 2.0.
- Write short HTML scripts using events (onload/keypress/keydown) and prompt/alert.
- Explain and demonstrate CSS box model and position properties.
- Differentiate internal, external, and inline CSS with examples.
- Explain XML namespace or XSLT with a small example.
- Explain AJAX and show XMLHttpRequest usage in a basic script.
- Explain JSON usage, data types, and parsing in JavaScript.

## Priority Order for Fast Revision

1. XML + DTD/XSD (definitions, syntax, conversion, constraints)
2. HTML form + JavaScript validation
3. jQuery selectors, animate, chaining, callback
4. CSS box model, selectors, and positioning
5. Web basics (client/server, static/dynamic, Web 1.0/2.0)
6. JavaScript events, arrays, DOM basics
7. JSON and AJAX/XHR

## Exam Attempt Guidance (Unit 1 to Unit 5)

- Prefer Section A questions from XML/XSD and form validation if available.
- In short questions, answer high-frequency theory first: web basics, CSS fundamentals, jQuery, XML terms.
- For script questions, keep syntax clean and include minimal but complete working structure.
- For compare questions, use table format with direct point-by-point differences.
