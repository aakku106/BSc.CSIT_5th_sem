# Web Technology (WT) — 1‑Day Marathon Plan (Target 30+)

This plan is based on repetition across **2076, 2078–2082 + Model** (7 sets total). Frequency means “topic appears in x out of 7 sets”.

## Assumptions

- You are starting from zero (no prior knowledge).
- You have only one day to prepare.
- Goal: **30+ marks** (pass-first, then safer buffer).

## What to optimize for (exam reality)

- **Section/Group A:** attempt any **2 out of 3** long questions
- **Section/Group B:** attempt any **8 out of 12** short questions

A practical “30+” approach:

- Lock **2 reliable long answers** first.
- Keep at least **10 short answers ready** so you can choose the best 8.

## 2) The “must cover” topics (based on repeats)

### P1 Core (non-negotiable in 1 day)

- **XML creation + DTD/XSD**
  - XML document structure, elements, attributes, simple/complex types
  - DTD vs XSD comparison and one full example
  - Namespace / XSLT / AJAX basics as short theory
- **HTML form + JavaScript validation**
  - Required field checks, pattern checks, checkbox/radio/select validation
  - DOM access (`getElementById`, `getElementsByTagName`) and event handling
- **PHP form + database insert/select**
  - DB connection, insert, select, display results
  - Form handling and validation basics
- **CSS practicals**
  - External/internal CSS, selectors, positioning, box model
  - shadow effects, text-overflow, media queries
- **Unit 1 definitions/comparisons**
  - HTTP, request/response, WWW, client/server, static vs dynamic, Web 1.0 vs Web 2.0

### P2 High (do after P1)

- **jQuery selectors / animate / chaining / callback**
- **PHP short programs**
  - strings, arrays, functions, class/object, inheritance, cookie/session
- **HTML short practicals**
  - lists, iframe, audio, canvas, table, meta tag, footer mailto, semantic tags
- **JSON**
  - parse, data types, use of JSON

### P3 Support (only if time remains)

- XHR/AJAX short theory
- XSLT and XML namespace details
- Responsive design / media queries

## 4) One-day schedule (hour-by-hour)

Use “Hour 0” as your start time. Study with a notebook and write answers.

### Hour 0: Setup (30–45 min)

Make a 2-page “exam sheet” that you will revise all day:

- XML: structure, elements, attributes, DTD, XSD, namespace
- PHP: connection, insert, select, function, array, class/object, cookie/session
- JavaScript: validation pattern, events, DOM access, prompt/alert
- CSS: selectors, box model, positioning, shadow, text-overflow
- HTML: form, meta, footer mailto, semantic tags, iframe, audio

Deliverable: 2 pages of headings you can rewrite from memory.

### Hours 1–2.5: Unit 5 — XML + DTD/XSD (P1)

Target outcome: one guaranteed Group A answer.

- Learn XML basics:
  - why XML is used, syntax rules, tree structure, elements vs attributes
- DTD and XSD:
  - DTD vs XSD comparison
  - simple type vs complex type
  - attributes, restrictions, and validation idea
- Practice ONE full long question:
  - **2079-A1** or **2082-A3** or **Model-A1**
- Practice one short theory set:
  - **2076-B8/B9**, **2078-B9**, or **2079-B10**

Deliverable: 1 XML + DTD answer and 1 XML + XSD answer.

### Hours 2.5–4.25: Unit 2 — HTML form + events + composition (P1)

Target outcome: strong support for Group A and Group B.

- Form elements, attributes, and validation flow
- DOM access:
  - `getElementById`
  - `getElementsByTagName`
- Events:
  - onload, keypress, keydown, mouseover/mouseout
- Small HTML tasks:

Practice:

- **2080-B5**, **2081-B6**, **2082-B6**, or **Model-B5** for events

### Hours 4.25–6.25: Unit 4 — JavaScript + jQuery + JSON (P1)
